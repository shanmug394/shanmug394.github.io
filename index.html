Making reliability measurable and actionable

I owned the Workload Success Rate (WSR) metrics program for Microsoft Fabric: one way to measure reliability across many workload teams.

Platform PMKPI strategyMetric governanceDependency managementOperational readiness

Problem

Each team onboarded differently and defined scenarios differently. Nobody could tell a real product failure from an instrumentation gap.

Action

Built the operating model: phased onboarding, shared definitions, data-quality triage, review cadence and a migration roadmap to Fabric.

Result

A production tenant-level investigation dashboard, wider scenario coverage, and one source of truth shared with the Quality Dashboard.
